# FP-project

This repository contains R code for our analyses of *Faecalibacterium* genomic diversity, taxonomy, functional variation, host and geographic distributions, microbial co-abundance, and associations with human phenotypes.

We also developed [Faecali Search](https://fulab.web.rug.nl/Faecali_search/), a web tool that helps identify candidate *Faecalibacterium* species by comparing uploaded genome sequences with our reference catalogue of 17,103 genomes spanning 83 species.

Scripts are available in [analyses/](analyses/). See [DEPENDENCIES.md](DEPENDENCIES.md) and [INPUTS.md](INPUTS.md) for software requirements and input formats. This repository provides code only; research data are not included.
